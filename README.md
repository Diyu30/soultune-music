# SoulTune – Full Stack Spotify Clone (MERN)

SoulTune is a full-stack music streaming application built with **React.js**, **Node.js**, **Express.js**, and **MongoDB**.  
The app provides a modern music player for users to browse, play, and search songs and albums.  

The project includes:  
- A **frontend website**  
- An **admin panel** to manage songs and albums  
- A **backend server** to handle authentication, playlists, and media storage (Cloudinary)

Users can register, log in, explore songs, and listen to their favorite music.  
The admin panel allows uploading songs, album images, and managing content.  
All media files are stored securely on Cloudinary, and user/song data is stored in MongoDB Atlas.  
The application uses JWT for authentication and Redux for state management.  
The design is fully responsive for desktop, tablet, and mobile devices.
